# 开源维护与本地同步

`itwanger/one-minute-remotion` 是对外安装、文档、问题反馈与发行包的主仓库。`vibe-science` 承载可公开演示的画面案例；作者本地的制作项目属于工作资料，不能作为外部使用者必须具备的依赖。

## 同步范围

从作者本地 Skill 同步阶段规则、写稿规范、视觉与动画方法、已公开的静帧、无个人配置的脚本改进。公开仓库保留独立 `assets/runtime/shared/`：初始化、音频导入、空 TTS 配置、模板与媒体检查，不直接覆盖成依赖作者工作区的工具。

不要将本地绝对路径、音色 ID、凭据、声音克隆模型、原始录音、项目锁文件、私人音频、头像或完整个人项目复制进发行包。既有公开 RRF 演示视频继续通过原 Release 链接供观看，不把它的声音配置变成使用者默认值。

## 需要保持一致的行为

- 1至2分钟目标，默认120秒，已有锁的目标不变；超时只提示，保留全文与语速。
- 主题 / 工具 / 版本目录，以及集合内固定版本的共享动画库、字体和色板。
- 配音试听、分镜确认、约30秒逐章审片、整片确认、明确导出，各阶段不能自动越过。
- 同时验证集合项目与已有独立项目；包内不要求作者的其他仓库或 Skill。

## 检查与发行

```bash
python3 -m unittest discover -s tests -v
python3 scripts/package_skill.py --output dist/one-minute-remotion.zip
git diff --check
```

检查 Markdown 相对链接、图片哈希、第三方许可与 ZIP 完整性；从包内初始化临时项目，安装共享资源并检查 TypeScript。不要为发布 Skill 调用付费 TTS 或重新渲染案例视频。

提交和推送仅包含本仓库本次改动。用户明确要求同步发布后，以新版本标签创建 GitHub Release，并上传完整 ZIP，保证目录安装与界面导入拿到同一版内容；不要覆盖既有发行版。发布后核对远端提交及附件 SHA-256。
